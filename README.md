# 📚 node-vite-xampp (Proyecto Inicial)

Este repositorio contiene el código inicial del proyecto, desarrollado durante las primeras etapas de aprendizaje con **Vite** y **XAMPP**.

---

## ⚠️ Proyecto Final Actualizado

El proyecto final ha sido migrado y mejorado significativamente. Ahora utiliza:

- **Next.js** con **shadcn/ui** para el frontend.
- **Node.js + Express** para el backend.
- **MySQL** como base de datos.
